Learn & Earn Hub Courses

Basic Computer Skills (English)

  • Microsoft Word: Learn document creation, formatting, saving files and printing.
  • Microsoft Excel: Learn tables, formulas, calculations and data management.
  • Microsoft PowerPoint: Learn presentations, slides and visual designs.
  • Notepad: Learn simple text writing and basic computer notes.
  • WordPad: Learn formatted text documents.
  • Microsoft Paint: Learn basic drawing and image editing.
  • Windows Basics: Learn files, folders, settings and computer management.
  • Internet Browsing: Learn searching, websites, email and online safety.

بنیادی کمپیوٹر کورسز (اردو)

  • مائیکروسافٹ ورڈ: ڈاکومنٹ بنانا، فارمیٹنگ، محفوظ کرنا اور پرنٹ کرنا سیکھیں۔
  • مائیکروسافٹ ایکسل: ٹیبل، فارمولے، حساب اور ڈیٹا مینجمنٹ سیکھیں۔
  • مائیکروسافٹ پاورپوائنٹ: پریزنٹیشن اور سلائیڈ بنانا سیکھیں۔
  • نوٹ پیڈ: سادہ تحریر اور نوٹس لکھنا سیکھیں۔
  • ورڈ پیڈ: فارمیٹ شدہ ڈاکومنٹ بنانا سیکھیں۔
  • پینٹ: بنیادی ڈرائنگ اور تصویر ایڈیٹنگ سیکھیں۔
  • ونڈوز: فائل، فولڈر اور کمپیوٹر استعمال کرنا سیکھیں۔
  • انٹرنیٹ براؤزنگ: ویب سائٹس، سرچ اور آن لائن حفاظت سیکھیں۔
