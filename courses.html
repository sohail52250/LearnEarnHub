Basic Computer Courses

Learn computer skills step by step. کمپیوٹر کی مہارتیں آسان طریقے سے سیکھیں۔

1. Microsoft Word

English: Learn typing, documents, formatting and professional letters.

اردو: ٹائپنگ، ڈاکومنٹ بنانا، فارمیٹنگ اور خطوط تیار کرنا سیکھیں۔

2. Microsoft Excel

English: Learn tables, calculations and basic data management.

اردو: ٹیبل، حساب کتاب اور ڈیٹا مینجمنٹ سیکھیں۔

3. Microsoft PowerPoint

English: Create presentations and slides.

اردو: پریزنٹیشن اور سلائیڈز بنانا سیکھیں۔

4. Notepad

English: Learn simple text writing and notes.

اردو: سادہ تحریر اور نوٹس بنانا سیکھیں۔

5. WordPad

English: Learn basic document editing.

اردو: بنیادی ڈاکومنٹ ایڈیٹنگ سیکھیں۔

6. Microsoft Paint

English: Learn drawing and image editing basics.

اردو: ڈرائنگ اور تصویر میں تبدیلی کی بنیادی معلومات۔

7. Windows Basics

English: Learn desktop, files, folders and settings.

اردو: ڈیسک ٹاپ، فائل، فولڈر اور سیٹنگز سیکھیں۔

8. Internet Browsing

English: Learn safe browsing, search and online services.

اردو: محفوظ انٹرنیٹ استعمال، سرچ اور آن لائن سروسز سیکھیں۔
