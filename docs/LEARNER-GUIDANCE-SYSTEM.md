# LearnEarnHub Learner Guidance System

**Status:** PLANNING / CANONICAL REFERENCE

**Baseline:** 3301166f836b098856033659f216ca492bcff417

## Purpose

> **Do not make the learner figure out what to do next. LearnEarnHub should tell the learner what to do next.**

## Target Journey

Main Page → Start Learning → Learning Hub → Study Plan / Course Catalogue → Course → First Lesson → Next Lesson → Progress → Assessment → Certificate

## Guidance

**Start Learning** — primary beginner entry point.

**Study Plan** — recommended for new learners.

**Course Catalogue** — direct access for learners who already know what they want.

**Returning learner:** Continue Learning → Active Course → Last Incomplete Lesson.

## Architecture Rule

Reuse the existing learning routes, APIs, identifiers, authentication, and learner state. Do not create duplicate learning or progress systems.
