Step-by-Step Learning Guide

Start from zero and learn practical computer skills step by step.

Beginner Path (English)

  1. Computer Basics: Learn mouse, keyboard, files, folders, desktop and Windows settings.
  2. Windows Skills: Learn how to open programs, manage files, install apps and browse safely.
  3. Microsoft Word: Create documents, write applications, format text and save files.
  4. Microsoft Excel: Create tables, use formulas, manage data and make calculations.
  5. Microsoft PowerPoint: Create presentations, add pictures and present ideas.
  6. Notepad & WordPad: Learn simple writing, notes and basic text editing.
  7. Microsoft Paint: Learn drawing, image editing and basic graphics.
  8. Internet Browsing: Learn searching, email, online learning and safe internet use.

ابتدائی سیکھنے کا راستہ (اردو)

  1. کمپیوٹر کی بنیادی معلومات: ماؤس، کی بورڈ، فائل، فولڈر اور ونڈوز سیکھیں۔
  2. ونڈوز استعمال کرنا: پروگرام کھولنا، فائل محفوظ کرنا اور محفوظ براؤزنگ۔
  3. مائیکروسافٹ ورڈ: دستاویز بنانا، لکھائی کو ترتیب دینا اور محفوظ کرنا۔
  4. مائیکروسافٹ ایکسل: ٹیبل، فارمولا اور حساب کتاب سیکھیں۔
  5. مائیکروسافٹ پاورپوائنٹ: پریزنٹیشن بنانا اور معلومات پیش کرنا۔
  6. نوٹ پیڈ اور ورڈ پیڈ: سادہ تحریر اور نوٹس بنانا۔
  7. مائیکروسافٹ پینٹ: ڈرائنگ اور بنیادی تصویر سازی۔
  8. انٹرنیٹ براؤزنگ: تلاش، ای میل اور محفوظ انٹرنیٹ استعمال۔
